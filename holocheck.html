HoloCheck : Checklist en Réalité Mixte

Unreal Engine 5 HoloLens 2 Blueprints UX/UI Design

HoloCheck est une application de réalité mixte développée pour les pilotes de l'hélicoptère Guimbal Cabri G2. Le système dématérialise les checklists de vol via une interface interactive ancrée dans le champ de vision, permettant de valider les procédures de sécurité sans quitter l'environnement des yeux.

1. L'appareil de référence

Le Guimbal Cabri G2 : l'hélicoptère biplace utilisé pour l'étude ergonomique.

2. Analyse du besoin et Problématique

Dans un cockpit exigu de 1,24 m de large, l'utilisation d'une checklist papier traditionnelle force le pilote à détourner le regard et à lâcher ponctuellement les commandes. HoloCheck supprime ces "ruptures d'attention" en projetant les informations essentielles directement dans le champ de vision.

Transformation de la documentation passive en une structure de données active.

3. Conception Ergonomique

🎤 Commandes Vocales Validation des étapes par la voix pour garder les mains sur les commandes.
🖐️ Hand Tracking Interaction naturelle par gestes pour manipuler les hologrammes.
📊 Suivi Dynamique Barre de progression en temps réel sur les 35 étapes de sécurité.
Interface optimisée pour maximiser le confort visuel et la sécurité.

4. Développement technique (UE5)

La logique logicielle utilise le système de Blueprints (scripting visuel). Le flux de données est surveillé en temps réel pour garantir une réactivité parfaite de l'interface.

Architecture logicielle gérant la validation séquentielle.

5. Validation sur Simulateur

Les tests finaux sur le simulateur de l'IUT de Cachan ont permis d'ajuster l'ergonomie et de valider l'absence d'obstruction visuelle en conditions réelles.

Mise en situation réelle sur le simulateur de l'IUT de Cachan.
