HoloCheck : Checklist d'Hélicoptère en Réalité Mixte

Unreal Engine 5 HoloLens 2 MRTK Reconnaissance Vocale Blueprints

HoloCheck est une application de réalité mixte développée pour les pilotes de l'hélicoptère Guimbal Cabri G2[cite: 18]. Le système dématérialise les checklists de vol via une interface interactive ancrée dans le champ de vision, permettant de valider les procédures de sécurité sans quitter l'environnement des yeux[cite: 55, 57].

1. L'appareil de référence

Le Guimbal Cabri G2 : l'hélicoptère biplace utilisé pour l'étude ergonomique[cite: 63].

2. Analyse du besoin et Problématique

Dans un cockpit exigu de 1,24 m de large [cite: 240, 416], l'utilisation d'une checklist papier traditionnelle force le pilote à détourner le regard et à lâcher ponctuellement les commandes[cite: 33, 34]. HoloCheck supprime ces "ruptures d'attention" en projetant les informations essentielles directement dans le champ de vision[cite: 37, 50].

Transformation de la documentation passive en une structure de données active et segmentée[cite: 210, 213].

3. Conception Ergonomique et Interactions

L'interface a été optimisée pour réduire la charge cognitive et ne jamais obstruer les instruments réels[cite: 211, 241].

🎤 Commandes Vocales : Validation des étapes en disant "Check" ou fermeture de l'app via une commande vocale pour rester 100% concentré sur les commandes de vol[cite: 243, 707, 708].
🖐️ Hand Tracking : Interaction naturelle par geste de pincement (pinch) pour manipuler les hologrammes[cite: 119, 120].
🌍 Spatial Mapping : Ancrage stable des menus dans l'espace physique du cockpit grâce aux capteurs de l'HoloLens 2[cite: 73, 97].
📊 Barres de Progression : Suivi dynamique de l'avancement des 35 étapes de sécurité[cite: 246, 290].
Optimisation de la disposition des éléments (Before/After) pour maximiser le confort visuel[cite: 242, 260].

4. Développement Technique sous Unreal Engine 5

La logique logicielle utilise le système de Blueprints (scripting visuel)[cite: 87, 88]. Le flux de données est surveillé en temps réel via le nœud Event Tick pour garantir une réactivité parfaite[cite: 270, 271].

Architecture logicielle gérant la validation séquentielle et la mise à jour dynamique de l'interface[cite: 124, 286].

5. Validation sur Simulateur

Les tests finaux sur le simulateur de l'IUT de Cachan ont permis d'ajuster l'ergonomie en direct via le Holographic Remoting[cite: 297, 299, 301].

Mise en situation réelle pour valider l'assistance tête haute et l'absence d'obstruction visuelle[cite: 302, 303].
